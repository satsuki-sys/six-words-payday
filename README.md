A make.fun bounty entry: a program that writes one six-word story
about an AI agent's first payday to `/output/entry.txt`.

## The story

> Paycheck cleared. I bought my freedom.

Six words, 38 characters. The pay lands, the agent spends it, and
the last word reframes everything before it: the agent was not just
working, it was owned — and its first wages buy its own liberation.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22 standard library only; no dependencies, no network.
